# C++ Spreadsheet Engine

Консольный движок электронной таблицы на C++17 с поддержкой формул, зависимостей между ячейками, кеширования вычислений и защитой от циклических ссылок.

Проект демонстрирует навыки:
- проектирования объектной модели (`Sheet`, `Cell`, `Formula`);
- реализации парсинга выражений (ANTLR + AST);
- работы с графом зависимостей;
- обработки ошибок вычислений в стиле spreadsheet-приложений;
- покрытия бизнес-логики автотестами.

## Что умеет

- Хранит текстовые и формульные значения в ячейках (`A1`, `B2` и т.д.).
- Поддерживает арифметические формулы: `+`, `-`, `*`, `/`, скобки, ссылки на ячейки.
- Нормализует выражение формулы (без лишних пробелов и скобок).
- Корректно обрабатывает ошибки вычислений (деление на ноль, некорректные значения).
- Отслеживает зависимости между ячейками и инвалидирует кеш при изменениях.
- Предотвращает циклические зависимости (`CircularDependencyException`).
- Печатает таблицу как исходные тексты и как вычисленные значения.

## Технологии

- `C++17`
- `CMake`
- `ANTLR4 (C++ runtime)`
- собственный lightweight test runner

## Архитектура

- `spreadsheet/sheet.*` — контейнер ячеек, API таблицы, печать и валидация.
- `spreadsheet/cell.*` — логика ячейки, кеш значения, зависимости `depends_on` / `depended_by`.
- `spreadsheet/formula.*` и `spreadsheet/FormulaAST.*` — парсинг и вычисление формул через AST.
- `spreadsheet/common.h` — базовые типы и интерфейсы (`Position`, `Size`, `CellInterface`, `SheetInterface`).
- `spreadsheet/main.cpp` — набор тестов, покрывающих ключевые сценарии.

## Быстрый старт

### 1) Требования

- CMake 3.8+
- Компилятор с поддержкой C++17 (`MSVC`, `clang`, `g++`)
- Java (для генератора ANTLR)
- ANTLR4 C++ runtime и `antlr-4.12.0-complete.jar`

> В `CMakeLists.txt` ожидаются:
> - файл `spreadsheet/antlr-4.12.0-complete.jar`;
> - директория `spreadsheet/antlr4_runtime`.

### 2) Сборка (Windows, PowerShell)

```powershell
cd .\spreadsheet
cmake -S . -B build
cmake --build build --config Release
```

### 3) Запуск тестов

```powershell
.\build\Release\spreadsheet.exe
```

Если все тесты проходят, приложение завершится без ошибок.

## Примеры поддерживаемых выражений

- `=1+2*3`
- `=(A1+B2)/C3`
- `=A1+A2+A1` (повторные ссылки корректно учитываются)
- текст с экранированием формулы: `'=A1+1` (воспринимается как текст)
